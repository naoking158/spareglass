spareglass の使い方 (Windows)
==============================

タブレットや別のパソコンのブラウザを、この Windows パソコンの
「2 枚目の画面」として使います。
両方の機器を同じ Wi-Fi (同じネットワーク) につないでおいてください。

必要なもの: Windows 10 / 11 (64 ビット)

使う前に確認すること
--------------------
- 同じネットワーク: パソコンともう一方の機器を、同じ Wi-Fi につなぎます。
  スマートフォンのテザリングでもかまいません。その場合はパソコンともう一方の
  機器の両方を、そのテザリングにつなぎます。
- ネットワークを「プライベート」にする: 設定 → ネットワークとインターネット →
  Wi-Fi → つないでいるネットワーク名 (Windows 11 では「(ネットワーク名) の
  プロパティ」) を開き、ネットワーク プロファイルを「プライベート」にします。
  「パブリック」のままだと接続できません。初めてつなぐネットワーク
  (テザリングを含む) は「パブリック」になることが多いので、新しいネットワークに
  つないだときは毎回確認してください。
- ファイアウォール: 初めて起動したときに「Windows セキュリティの重要な警告」が
  出たら、「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を
  押します (「1. 起動する」も参照)。
- VPN やセキュリティソフト: 会社のパソコンなどで VPN やセキュリティソフトが
  動いていると、もう一方の機器からの接続が止められることがあります。
  つながらないときは VPN を切って試し、それでもだめならパソコンの管理者に
  確認してください。

1. 起動する
-----------
このフォルダの「spareglass.exe」をダブルクリックします。

初回だけ「Windows によって PC が保護されました」と表示されたら、
「詳細情報」→「実行」を押します。

初回だけ、2 枚目の画面を作るためのドライバを自動で入れます。
黒いウィンドウに「Installing the Virtual Display Driver」と出たあと、
Windows の確認が出るので、次のように答えます。
  1) 「このアプリがデバイスに変更を加えることを許可しますか?」→「はい」
     (管理者のパスワードを聞かれたら、このパソコンの管理者に入力してもらいます)
  2) 「このデバイス ソフトウェアをインストールしますか?」→「インストール」
「The Virtual Display Driver is installed.」と出たら完了です。
途中でディスプレイが 1 つ増えることがありますが、自動で外れます。

このドライバは driver フォルダに入っている Virtual Display Driver
(MIT ライセンス, https://github.com/VirtualDrivers/Virtual-Display-Driver) です。

「Windows セキュリティの重要な警告」(ファイアウォール) が表示されたら、
「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押します。
これを許可しないと、もう一方の機器から接続できません。

ブラウザで「spareglass」のページが開き、QR コードと
http://192.168.x.x/1 のようなアドレスが表示されたら準備完了です。
使っている間は、黒いウィンドウとこのページを開いたままにしてください。

2. もう一方の機器でつなぐ
------------------------
タブレットなどのブラウザで、spareglass のページに出ているアドレスを開きます
(カメラで QR コードを読み取っても開けます)。
「Connect」を押すと 4 桁の番号が表示されます。

パソコンの spareglass のページに「接続を許可しますか」と同じ番号が出るので、
番号が同じことを確かめて「許可する」を押します (違うときは「許可しない」を押します)。
もう一度「Connect」を押すと、パソコンの 2 枚目の画面が表示されます。
許可した機器は覚えているので、次からは Connect を押すだけです。

ウィンドウをマウスで右側へ動かすと、もう一方の機器に表示されます。
画面の並びは 設定 → システム → ディスプレイ で変えられます。

3. 終わる
---------
spareglass のページの「spareglass を終了する」を押します。
(黒いウィンドウで Ctrl キーを押しながら C を押しても終わります。)
2 枚目の画面は自動で外れます。

うまくいかないとき
------------------
- 「このサイトにアクセスできません」「接続が拒否されました」
  (ERR_CONNECTION_REFUSED) と出る: 上から順に試し、直ったらそこで終わりです。
  1) spareglass が動いているか確かめる: 黒いウィンドウを閉じた、
     「spareglass を終了する」を押した、パソコンを再起動した場合は止まっています。
     「spareglass.exe」をダブルクリックして起動し直してください。
  2) spareglass のページに今出ているアドレスを開き直す: アドレスは起動し直したときや
     Wi-Fi をつなぎ直したときに変わることがあります。ブックマークや履歴からではなく、
     ページの QR コードを読み取るか、今出ているアドレスを入力し直してください。
  3) アドレスを最後まで入力したか確かめる: 「http://192.168.1.20:7878/1」のように
     「:7878」が付いているときは、それも省かずに入力します。
     「https://」ではなく「http://」で始まっているかも確かめます。
  4) ページに「開けないときはこちらも試してください」と別のアドレスが出ていれば、
     そちらを開きます。
- 上のほかのエラーでアドレスを開けない: 「使う前に確認すること」を確認してください。
  ファイアウォールの警告で許可しなかった、または「パブリック」だけを許可した場合は、
  Windows セキュリティ → ファイアウォールとネットワーク保護 →
  ファイアウォールによるアプリケーションの許可 → 「設定の変更」を押し、
  一覧の spareglass の「プライベート」にチェックを入れて「OK」を押します。
  ページに「開けないときはこちらも試してください」と別のアドレスが出ている場合は、
  そちらも試してください。
- spareglass のページを閉じてしまった: 黒いウィンドウの「Host page」の行にある
  http://127.0.0.1:...#... のアドレスを、# の後ろも含めて行の最後までブラウザで開きます。
- spareglass のページが英語で出る: ブラウザの言語が日本語以外のときは英語で表示されます。
  「接続を許可しますか」は A device wants to connect、「許可する」は Allow、
  「許可した機器」は Allowed devices、「削除」は Remove、
  「spareglass を終了する」は Quit spareglass です。
- 「Virtual Display Driver is not installed」と出る: 黒いウィンドウを閉じて、
  spareglass.exe をもう一度ダブルクリックし、Windows の確認に
  「はい」「インストール」で答えてください。
  「extract the whole zip」と出る場合は、zip を開いただけで展開して
  いません。zip を右クリック →「すべて展開」してから、展開したフォルダの
  spareglass.exe をダブルクリックしてください。
  何度やっても入らないときは、driver フォルダの
  VirtualDisplayDriver-setup.exe を開いて画面の案内どおりに進めます
  (最後の画面の「Launch VDD Control」のチェックは外します)。
- ドライバを入れるときに「インストール」を押さなかった、または
  「display did not appear」「installed but not running」と出た: 設定 → アプリ で
  「Virtual Display Driver」をアンインストールしてから、
  spareglass.exe をもう一度ダブルクリックしてください。
- 「You must install .NET Desktop Runtime to run this application.」と出た:
  ドライバの setup を直接開いたときに、ドライバ付属の管理アプリが
  出すメッセージです。spareglass には要らないので「いいえ」を押してください。
  ドライバはそのまま使えます。
- 同時に使える 2 枚目の画面は 1 台までです。
